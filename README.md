# Sub-on

Sub-on is a simple Python tool that utilizes the `httpx` tool with the `subprocess` module to check active subdomains quickly and efficiently.

---

## Features

- Fast subdomain checking
- Uses `httpx`
- Simple CLI interface
- Save active subdomains to file

---

## Installation

```bash
git clone https://github.com/YogaRmdn/Sub-on
cd Sub-on
pip install -r requirements.txt
```

---

## Usage

```bash
python subon.py
```

---

## Example

```bash
[?] File target : /home/kali/sub_usti.txt
[?] Output file : hai.txt

[1] https://apikindi.usti.ac.id
[2] https://arsdok.usti.ac.id
[3] https://cbt.usti.ac.id

[+] Found 18 subdomain active
```
